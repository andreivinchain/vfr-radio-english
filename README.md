# VFR Radio English — Польша

Мобильный тренажёр радиообмена на английском для VFR-полётов. Один экран — одна реплика:
**послушал → ответил → сверил** по ключевым элементам readback. Эфир на английском, разборы на русском.

Сценарии: EPGD (Gdańsk, CTR класса D) → выход через GOLF → FIS Gdańsk Information → EPEL (Elbląg Radio),
плюс сложные указания, возврат по погоде со входом в CTR, нештатные ситуации (PAN PAN, MAYDAY, 7600, потеря ориентировки).

## Запуск
Открыть `index.html` в браузере или через GitHub Pages. Зависимостей нет.

## Озвучка
По умолчанию — браузерный TTS. Для реалистичной нейросетевой озвучки с «эфирным» фильтром:
```
pip install edge-tts          # нужен ffmpeg
python3 tools/gen_audio.py    # создаст audio/*.mp3
```
Приложение само подхватит файлы из `audio/`.

## Источники
Фразеология — Part-SERA (раздел 14), ICAO Doc 9432; частоты и VFR-точки — AIP Польши на дату создания.
Учебное пособие, не для оперативного использования. Позывной SP-KAB вымышленный.
